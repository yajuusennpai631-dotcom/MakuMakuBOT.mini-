# マクマクBOT Mini

マクマクBOT Miniは、Discord上でAIに質問できるBotです。

AIのほかに、Web検索、AFK、サーバー情報・ユーザー情報の表示、ウェルカムメッセージ、認証などの機能があります。

## AIを使う

`/ai` からAIに質問できます。

``` text
/ai question:質問内容
```

AIはチャンネルごとに直近の会話を一時的に覚えているため、続けて質問することもできます。

AIがチャンネルの会話に勝手に反応することはありません。AIが応答するのは
`/ai` を使用したときだけです。

### 利用回数

一般ユーザーは1人あたり1日5回まで利用できます。

回数はすべてのサーバーで共通で、日本時間の0:00にリセットされます。

`/ai_left` から、その日の残り回数を確認できます。

AIが準備中だった場合や、混雑・タイムアウト・エラーなどで回答できなかった場合は回数を消費しません。

一部のユーザーは特別ユーザーとして設定されている場合があり、その場合は回数制限なしで利用できます。

## Web検索

`/ai` は、必要に応じてWeb検索を使って回答できます。

「検索して」「最新」「ニュース」「天気」「株価」など、現在の情報が必要そうな質問では自動的に検索します。

また、`web` オプションから検索するかどうかを指定できます。

-   `web:True`：Web検索を使う
-   `web:False`：Web検索を使わない
-   未指定：質問内容から自動で判断する

Web検索を行った場合は、回答の下に参照したページが表示されます。

## 使用しているAI

AIには `Qwen3-4B-Instruct-2507` のローカルモデルを使用しています。

AIの推論処理はBotが動いている環境で行われ、質問への回答を生成するために外部のAIサービスへ質問内容を送信する仕組みは使用していません。

ただし、Web検索を使用した場合は、検索に必要な検索語が検索サービスへ送信されます。

起動直後など、モデルの準備が終わっていない場合はAIをすぐに利用できないことがあります。その場合は、準備が完了してからもう一度
`/ai` を使用してください。

AIの処理は1件ずつ行われるため、利用が集中している場合は「混雑中」になることがあります。

## その他のコマンド

| コマンド | 内容 |
|---------|------|
| `/ai` | AIに質問します |
| `/ai_left` | 今日のAIの残り利用回数を確認します |
| `/ping` | Botの応答速度を表示します |
| `/help` | 利用できるコマンドを表示します |
| `/serverinfo` | 現在のサーバーの情報を表示します |
| `/userinfo` | ユーザーの情報を表示します |
| `/afk` | AFK（離席）状態にします |

`/afk`
でAFK状態にすると、AFK中にメンションされた際に離席理由が表示され、本人が再び発言すると自動的に解除されます。

## サーバーごとの機能

サーバー管理者は、ウェルカムメッセージと認証パネルを設定できます。

認証パネルが設置されているサーバーでは、「認証する」ボタンを押すことで設定されたロールを受け取れます。

マクマクBOT MiniにはモデレーションやAutoMod機能はありません。

# プライバシーポリシー

このプライバシーポリシーでは、マクマクBOT
MiniがDiscord上で扱う情報と、その利用目的について説明します。

## 1. Botが扱う情報

本Botは、機能を提供するために必要な範囲でDiscordから取得できる情報を扱います。

現在の実装では、主に次の情報を利用します。

-   DiscordのユーザーID
-   DiscordのサーバーID、チャンネルID、ロールID
-   ユーザー名・表示名など、コマンドの処理や表示に必要なDiscord上の情報
-   `/ai` に入力された質問内容
-   AIの利用回数
-   AFKに設定した理由と設定時刻
-   ウェルカムメッセージや認証ロールなど、サーバー管理者が設定した内容
-   特別ユーザーとして設定されたユーザーID、設定者のユーザーID、設定時刻

Discord上でBotがアクセス可能な情報の範囲は、Discord側の仕様、Botに付与された権限、サーバーの設定などによって変わる場合があります。

## 2. AIの会話履歴

`/ai`
の質問とAIの回答は、会話を続けられるようにするため、チャンネルごとの短期的な会話履歴としてBotのメモリ上に保持されます。

現在の実装では、このAI会話履歴を永続データへ保存していません。Botが再起動すると、この短期会話履歴は失われます。

質問内容や回答内容を、AIモデルの追加学習・トレーニング用データとして利用する機能も現在の実装にはありません。

## 3. 永続的に保存される情報

Botの再起動後も機能を維持するため、次のような情報はBotのデータファイルに保存されます。

-   サーバーごとのウェルカム設定
-   サーバーごとの認証ロール設定
-   AFK状態、AFK理由、設定時刻
-   ユーザーIDごとの当日のAI利用回数
-   特別ユーザーの設定情報

これらは、本Botの機能を提供するために使用します。

## 4. Web検索

Web検索を利用する場合、質問内容をもとに作成した検索語が外部の検索サービスへ送信されます。

現在の実装では、通常はDuckDuckGoを利用し、運用環境にBrave Search
APIの設定がある場合はBrave Searchを利用します。

検索サービス側で行われる情報の処理については、それぞれのサービスが定めるプライバシーポリシー等が適用されます。

Web検索を利用したくない場合は、`/ai` の `web` オプションを `False`
にすることで検索を無効にできます。

## 5. 利用目的

取得・保存した情報は、主に次の目的で利用します。

-   本Botの各機能を提供するため
-   AIの利用回数を管理するため
-   AIの短期的な会話文脈を維持するため
-   AFK、ウェルカム、認証機能を動作させるため
-   不具合の調査やBotの安定運用を行うため
-   不正利用や運用妨害に対応するため

## 6. 第三者への提供

本Botが扱うDiscord上の情報を、広告目的で販売したり、データブローカーへ提供したりすることは想定していません。

ただし、Web検索を利用した場合は検索に必要な情報が検索サービスへ送信されます。

また、法令に基づく開示が必要となる場合など、正当な理由がある場合を除きます。

本Botのホスティング環境など、Botの運用に必要なサービス上でデータが処理・保存される場合があります。

## 7. データの保存期間

AIの利用回数は日単位で管理され、日付が変わった後に次回利用回数を確認・利用した際、当日の回数データへ更新されます。

AFK情報は、本人がDiscord上で発言してAFKが解除されるまで保存されます。

サーバー設定や特別ユーザー設定などは、機能上必要な間保存されます。

バックアップや破損時の退避ファイルが作成される場合があるため、削除や変更が直ちにすべてのバックアップへ反映されない場合があります。

## 8. データの削除について

自身に関する本Botの保存データの確認・削除を希望する場合は、本Botの開発者・運営者へ連絡してください。

本人確認や対象データの特定のため、DiscordのユーザーIDなどの情報を確認する場合があります。

サーバーに関する設定データについては、サーバー管理者からの依頼であることを確認する場合があります。

法令上の保存義務などがある場合を除き、機能提供に不要となったデータについては、合理的な範囲で削除に対応します。

## 9. セキュリティ

保存データについて、不正アクセス、紛失、破損などを防ぐため、合理的な範囲で管理を行います。

ただし、インターネット上のサービスである以上、完全な安全性を保証するものではありません。

## 10. Discordについて

本BotはDiscord上で動作する第三者製のBotであり、Discord
Inc.が提供・運営するBotではありません。

Discord自体による情報の取得・利用については、Discordのプライバシーポリシーなどが適用されます。

## 11. ポリシーの変更

Botの機能、保存する情報、外部サービス、運用方法などが変更された場合、このプライバシーポリシーも更新される場合があります。

重要な変更がある場合は、可能な範囲で分かりやすい方法により案内します。
